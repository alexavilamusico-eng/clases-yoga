Cómo se usa

Arriba hay dos pestañas:

Glosario — todas las posturas. Toca una tarjeta para ver el reverso: cómo entrar, beneficios, precaución, etiquetas, posturas relacionadas y «Cambiar dibujo». La estrella ★ marca favoritas. El buscador entiende nombre, sánscrito y también etiquetas (escribe «cadera», «torsión», «restaurativa»…). «Filtros» abre el panel para acotar.

Clases — el cuaderno digital. «+ Nueva clase» abre el constructor: eliges una semilla (un tema, una parte del cuerpo o una dinámica) y armas la clase por bloques. En cada bloque puedes añadir posturas, textos (lectura, pranayama, transición) o pedir sugerencias. Cada postura lleva lado, duración y nota. Al terminar, «Guardar y volver»: queda en el banco para reabrirla, duplicarla o darla.

Modo clase — desde una clase guardada, «Dar clase» abre el modo pantalla completa con timer, para seguir la secuencia mientras la impartes.

Respaldo — en Clases, «Respaldo» copia todas tus clases como texto. Guárdalo de vez en cuando: los datos viven solo en este navegador.

Créditos y licencias

Ilustraciones de posturas. Colección «Yoga Poses» de SVG Repo (svgrepo.com) — 64 dibujos de figura en un solo estilo, licencia libre / CC0. Se les quitó el círculo de fondo; sin otras modificaciones. Los 64 quedan dentro de la app: en cada tarjeta, «Cambiar dibujo» permite asignar o corregir el dibujo de cualquier postura (la elección se guarda en este navegador).

Datos de las posturas. 48 posturas parten de yoga-api (alexcumplido, código MIT; textos de dominio público), traducidas y resumidas. El resto tiene ficha redactada para esta app: las marcadas «Ficha breve — por completar» traen lo esencial y están pensadas para que Andrea las complete. Las cues en español, las etiquetas de nivel / zona / dinámica / tema y las precauciones son contenido propio y deben revisarse con criterio de maestra.

Posturas sin dibujo asignado. Muestran una tarjeta con el nombre sobre fondo degradado. Andrea puede asignarles uno de los 64 dibujos desde «Cambiar dibujo», o dejarlas así.
